# MB4 Rev E — 曲線・後方左右固定の試作設計

4弦ベース用、弦間19 mm、各弦独立、CNC切削2部品／弦。Jazz Bass／Precision Bass系の新規穴あけ用の提案です。特定機種・既存取付穴への適合は未確認です。単位mm。2026-10-05。

## 今回の変更

後壁頂部を真円R9のアーチへ変更し、左右リブを押出しの二次曲線にしました。リブの露出縁R0.6、壁の前後外周R0.8、中央前根元R1。ベース外形R4、前上縁R0.5、後方上縁R0.6。アンカー外形R3、前上縁R1.2、下面R0.3。丸みは表示だけでなく個別STEPの実ソリッドに含まれます。ねじ座・ボール保持肩・支持平面は機能寸法を優先します。

後リブの後ろに左右2穴を採用。各弦は前1＋後2＝3本、4弦で12本の木ねじです。後方穴はX=±4.5,Y=85、座面板厚5、皿座深さ1.6、底残り3.4。中央のM4調整ねじ頭から離して、組立状態で縦にφ6のドライバー進入域を確認しました。

この配置のため奥行82→90 mmに延長。前穴も(0,4)→(0,5)へ移動しました。旧版のテンプレートは使用せず、Rev E専用のPDF／DXFで位置を実測してください。全幅75 mm、弦中心X=−28.5,−9.5,9.5,28.5。既存5穴とは非互換です。

## 維持する機構

- 弦中心高さH=8+g、g=0〜12、設計上の最低8／最高20 mm。φ6×厚4.75の参考ボールに基づくため、実弦の巻き・ボール形状で弦軸は変わります。
- アンカー前端q=8〜20、肩Y=q+6=14〜26、前後調整12 mm。
- M4×35全ねじ＋DIN433小径座金＋圧縮ばね。ばね作動長17〜5。弦張力は後方ねじが受け、ばねは位置決め用です。
- 高さはM3平先4本／弦。固定はM3全ねじ2本／弦、座金／スペーサ外径6以下。高さに応じた長さと座金厚はPDF5頁で選択。
- 裏面φ12.5／深さ1.5の個別ピエゾ窪み。素子・接着・配線の総厚1.2以下を想定。4chの信号読出しは個別バッファを使用し、共通木部からのクロストークは実測評価します。

## 加工・発注

`cad/step/B03_organic_base.step`（A6061-T6）×4、`A04_organic_anchor.step`（C3604）×4。組立STEPは組付け参照用で、金物・弦・ボール・ピエゾ外形は参考形状です。タップはCADでは下穴のみ：図面指示どおりM3×0.5-6H／M4×0.7-6Hへ加工してください。

`RFQ_CNC.md`、`features.csv`、10頁PDFをSTEPと一緒に渡してください。曲線は平面押出しと一定Rを中心に構成し、3軸切削・反転・後端穴加工を想定しています。曲線・R・増肉の加工パスは増えるため、加工先で工具径・段取り・費用を確認します。今回は試作見積用であり、量産・実機強度の認定済み設計ではありません。

## 確認済みと評価範囲

個別部品の有効ソリッドとSTEP再読込、64ソリッドの組立、q=8/14/20×g=0/6/12の9条件で干渉を確認しました（ねじの嵌合は除外）。高さ1201点で固定ねじ先端Z0.2〜0.7、参考ボールの装填4位置、後方工具進入域も確認。`cad/geometry_check.json`に記録しています。

350 N／弦、最大弦高20、同じM4軸高さ19の片持ち梁断面比較では、後壁の最大公称曲げ応力はRev D 31.2→Rev E 26.1 MPa、約16.4%低下しました。断面係数からの簡易比較でありFEAではありません。後方増肉フランジ・固定パッドを除外し、局所応力集中・ねじ締付け・接触・基板変形・疲労・木部を考慮していません。後方木ねじ追加の強度効果は定量化していません。350 Nは比較用仮定で、実測・推奨・許容張力ではありません。

まず1弦分を試作し、実弦保持・支持剛性・木ねじ保持力・緩み・疲労・ピエゾの感度と分離度を評価してください。ボディ端余白、穴位置、木部厚、既存穴や空洞、必要な弦高は実機で確認します。

## データの再生成

CadQuery/OCP・ezdxf・ReportLab等は`cad/requirements.txt`参照。Blenderは別途必要です。

```bash
.venv/bin/python output_revE/cad/build_bridge.py
.venv/bin/python output_revE/cad/compare_sections.py
blender --background --python-exit-code 1 --python output_revE/cad/render_bridge.py
.venv/bin/python output_revE/cad/make_documents.py
```

`parameters.json`は設計寸法の一覧で、全寸法が自動連動するパラメトリックモデルではありません。形状変更には`build_bridge.py`のスケッチ・R選択と図面も更新し、干渉検査を再実行してください。`cad/reference/RevD_B02_base.step`は断面比較の参照専用で、発注対象外です。
