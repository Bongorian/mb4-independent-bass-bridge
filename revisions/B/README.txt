MB4 / 4弦独立サドルレス・ブリッジ 試作設計 Rev B
================================================
用途：汎用ジャズベ／プレベを想定した、新規取付穴を使う試作。
弦間19 mm。既存Fender系5穴への互換性はありません。
完成品寸法・実弦・木部の状態を確認する前の量産発注用ではありません。
外周にRを追加した改訂版です。まずPDFの1ページ目と9ページ目をご覧ください。

cad/step/ の部品STEP 3種類を各4個ずつ加工します。
ねじ穴はCAD上では下穴径。M3x0.5の指示はPDFとfeatures.csvが優先します。
STEPはmmのソリッドです。STLとblendは説明・表示用で、CNCの加工原本ではありません。
assembly STEPには市販金物の簡略形状とピエゾの参考外形を含みます。
弦高はボディ表面から15-20 mmを想定。弦の実際の支点はボールエンド／巻き部分で
変わるため、最後は実弦で高さ・オクターブを測ります。

cad/parameters.json と cad/build_bridge.py が再生成用ソースです。
python -m venv .venv
.venv/bin/pip install -r cad/requirements.txt
.venv/bin/python cad/build_bridge.py
弦間はparameters.jsonで変更できます。その他寸法を変える際は、穴座標・逃げ寸法も
build_bridge.pyとPDF生成用ソースで合わせて更新してください。

加工のポイント：ベース／キャリッジはA6061-T6、アンカーは快削黄銅C3604。
3軸フライス＋反転＋側面の穴加工で作成。旋盤専用部品、5軸加工、特殊なリングは不要。
ただしM3下穴・長穴には細径工具を使います。必ず加工業者に保持方法を含めて見積依頼。
各弦のピエゾは接着型の接触センサ用。張力を薄いセラミックに直接負担させません。
ピエゾ品番・接着層・出力・分離度は未確定。ポケットはφ12以下の参考外形用です。

納品物：PDF図面、部品／組立STEP、原寸DXF、部品表CSV、穴・加工フィーチャーCSV、
再生成ソース、Blender表示モデル、外観PNG、geometry_check.json。
PDFで示す組立寸法・標準金物寸法を参照。ソリッド整合性と可動限界の干渉は確認済。
実機取付、強度保証、音質保証、完全な各弦分離、CAM工具経路の保証は含みません。
ボールは外径6 mm、厚さ4.75 mmを参考にφ8の穴を設計。
上側スリットから抜けないため、ボールの最小厚さ3.8 mm以上を想定します。
この寸法は全メーカー共通の保証値ではありません。使用する弦で必ず確認してください。

Rev Bの追加形状：
ベース外周四隅R3、キャリッジ／アンカー外周四隅R2、外周の上下稜線R0.2。
後壁の四隅R1.5、上面外周R1。アンカー上側のスリット長辺にR0.2。
これらのRは加工用STEPに含まれます。外周平面Rは輪郭加工、稜線Rは仕上げパスを追加。
主要穴・溝の寸法と、座面・弦保持肩・ピエゾ接着面の高さはRev Aから維持。
残る穴口等はC0.1以下でバリ取り。PDFとfeatures.csvの指定Rは省略しないでください。
2D図では小Rと側面Rの遷移を簡略表示しています。STEPとR一覧を合わせて参照。
