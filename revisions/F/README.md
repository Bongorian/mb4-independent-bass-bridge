# MB4 Rev F — 後方1穴・一体クラウン・ミスミ標準金物

4弦、弦間19 mm、各弦独立、CNC切削2部品／弦。汎用Jazz/P Bass系の新規穴あけ用の試作案です。特定機種・既存穴への適合は未確認。単位mm、2026-10-05。

## 変更点

- 後方の木ねじ穴を左右2穴から中央1穴（X0/Y85）へ。前X0/Y5と合わせて2本／弦、計8本。後方座面厚5、皿座底残り3.4、曲線リブを維持。奥行90は工具域を残すため維持。
- アンカーを先端R7・丸いφ12クラウン・ゆるいくびれへ変更。本体高さ8、保持部だけ最高10。一体加工なので別のtone pin、横穴、止め輪は追加しません。球受けの窪みをY6〜17へ短くして後方タップ前の肉を残しました。
- 高さはM4平先（穴X±5/Y15,20.5）へ。MSSFS4-8/12/16を小ロットで購入でき、M3×16の1000本箱を避けられます。外側の肉を残すため穴を内側へ移動。
- 後方ねじはM4×35全ねじから、汎用SCB4-30（M4×30・半ねじ20）へ。前後の調整12 mmを維持し、首下の非ねじ部がアンカーへ入らない配置にしました。
- ばねはMISUMI UY6-20（急ぐ場合はE-GUY6-20）を参照。外径6、線径0.35、自由長20、k=0.098 N/mm。中央壁の前根元Rを0.8にして最低位置のばね外径を逃がしました。

丸みはSTEPの実ソリッドに含まれます。Ray Rossの球端から弦を伸ばす構成を参考にした独自のクラウン保持構造です。同製品のtone pin機構、音質、低摩擦、弦寿命を再現したとの評価はしていません。

## 調整と購入

弦中心H=8+g、g=0〜12（公称8〜20）。φ6×厚4.75参考ボールの軸に基づくため、実弦の結び・巻き部で弦軸は変わり得ます。高さ平先はg≤4でL8、4<g≤8でL12、8<g≤12でL16。ねじ掛かりは公称4〜8。

前端q=8〜20、保持肩Y=q+6=14〜26。SCB4-30の頭座Y73.5、先端Y43.5。アンカーへの公称ねじ重なり6.5〜18.5、非ねじ部先端Y63.5とアンカー最大後端Y62の隙間1.5。実物の面取りと不完全ねじを除いた有効掛かり6以上、首下の干渉を試作で確認します。

ばね作動長17〜5。公称力0.294〜1.47 N。自由長公差±1.5を考慮し、作動長≥実測自由長−15に合わせます。自由長21.5の場合は最短6.5、q最大18.5まで。**12 mmは公称寸法での前後調整幅で、全ロットで保証する幅ではありません。** ばねは位置を戻す部品で、弦張力の受けは後方ねじと固定部です。

固定用はM3頭付き2本／弦。長さ12/16/20/25と外径6以下の座金・スペーサで合わせます。PDF5頁の式・表を使い、ねじ先端Z0.2〜0.7に調整して木部への突出を防止。実測したgと金物の公差で厚さを微調整します。高い弦高では金物の交換が必要です。

MISUMI_purchase_options.csvに型番、数量条件、通常価格・納期割引価格、確認状態とURLを記載。hardware_sources.txtには小ロット向けの選び方を記載。価格は2026-10-05の公開表示・見積表示、税別、購入時再確認。発注・購入は行っていません。

## CNC発注

個別STEP：cad/step/B04_single_rear_base.step（A6061-T6）×4、A05_crown_anchor.step（C3604）×4。まず各1個の試作推奨。RFQ_CNC.md、features.csv、10頁PDFを併用。組立STEPの金物、弦、ばね、ピエゾは参考外形で切削対象外。ねじは螺旋を省略し、タップは下穴のみ表現：M3×0.5／M4×0.7-6Hで加工。

平面曲線の押出し、円筒、一定Rを中心に3軸切削＋反転＋後端穴加工を想定。Rは工具パス・段取りが増えるため、加工先で精度・工具径・費用を確認します。一般寸法±0.10、機能穴・座標±0.05、指定R±0.05、接触面平面度0.05／Ra3.2目安。

PDF7頁とDXFは新規取付用。全幅75、奥行90、弦中心X=−28.5,−9.5,9.5,28.5。既存5穴とは非互換。原寸100%で印刷して50 mm枠を実測し、ボディ端余白・木部厚・既存穴・空洞・スケール補正量を確認して穴位置を決定します。

## ピエゾと確認範囲

裏面φ12.5深さ1.5の窪みへ、各φ12以下の素子を金属裏面に接着。素子・接着・配線の総厚1.2以下、木部まで0.3以上離して圧壊を避けます。各素子を別バッファで読み、共通木部を通るクロストークを4ch録音で評価します。

個別STEPの有効ソリッドと再読込、64ソリッドの組立、q=8/14/20×g=0/6/12の9条件、高さ1201点、参考ボールの装填4位置を確認。後方のドライバーφ6進入域とばね外径φ6の包絡域を9条件で追加確認。cad/geometry_check.jsonとcatalogue_envelope_check.jsonに記録。ねじ嵌合部分は干渉判定から除外。

実物の公差、球端・巻き部との適合、強度、疲労、緩み、木ねじ保持力、音響は未検証。Rev Eの簡易断面応力値を本版の強度値に転用していません。まず1弦分で確認後に4弦へ進みます。
